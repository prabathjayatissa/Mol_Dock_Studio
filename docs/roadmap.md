# Roadmap

MolDock Studio is built in phases. **A phase is only marked complete when its
code is written, tested and documented** — there are no placeholder handlers
presented as finished features. The single source of truth for status is
[`backend/app/core/roadmap.py`](../backend/app/core/roadmap.py), which is served
by `GET /api/health` and rendered in the frontend Workflow panel. This document
explains it.

## Phase 0 — Foundation ✅ implemented

Repository layout, pinned dependency environment (`uv.lock`), SQLAlchemy models
(14 tables), the artifact store, the subprocess job layer, capability
reporting, the test harness and the initial documentation.

Known gap (recorded in `/api/health`): schema creation uses
`Base.metadata.create_all` on startup for the SQLite deployment. Alembic is
scaffolded for versioned/PostgreSQL deployments but autogenerated migrations
are not yet committed.

## Phase 1 — Molecular viewer ✅ implemented

- Projects and the full import path: PDB, mmCIF, SDF/MOL, MOL2, XYZ, PDBQT,
  plus FASTA sequences and RCSB fetch-by-ID.
- An original Three.js rendering engine (no third-party viewer): lines, stick,
  ball-and-stick, space-filling, backbone trace, cartoon ribbon and computed
  molecular surfaces.
- Selection, picking, measurements, labels, multiple colouring schemes.
- Exact van der Waals and solvent-accessible isosurfaces.
- Structure export (PDB/mmCIF/SDF/MOL2/XYZ) and PNG figures.

**Explicitly pending** (recorded in `/api/health`):

- Electrostatic-potential colouring — needs partial charges and a
  Poisson–Boltzmann solve; scheduled with preparation in Phase 2.
- Connolly solvent-*excluded* surface — Phase 1 ships exact vdW and
  solvent-accessible surfaces only.
- Binary (base64 typed-array) structure transport for >100k atoms; JSON packets
  are used now and their size is measured in tests.

## Phase 2 — Receptor and ligand preparation ⏳ pending

Chain/water/cofactor policy, hydrogen addition, protonation-state assignment,
Meeko PDBQT generation, ligand conformer ensembles, binding-site definition and
an interactive docking box with reference-ligand redocking.

## Phase 3 — Molecular docking ⏳ pending

The `DockingEngine` adapter for AutoDock Vina, background execution on the job
layer, a ranked pose table, pose visualisation and symmetry-aware RMSD. The
proposed first benchmark is redocking benzamidine into trypsin (PDB **3PTB**)
and comparing to the crystal pose.

> Docking scores are approximate scoring-function outputs. They are **not**
> measured binding affinities and must never be presented as clinical or
> experimental evidence.

## Phase 4 — Interaction analysis ⏳ pending

Hydrogen bonds, hydrophobic contacts, salt bridges, aromatic stacking,
cation–π, halogen bonds, metal coordination, 2D interaction diagrams and
per-pose reports.

## Phase 5 — Virtual screening ⏳ pending

Streaming compound-library import, a batch docking queue, ranking/filtering and
CSV/Excel/JSON export.

## Phase 6 — Advanced capabilities ⏳ pending

MD integration (GROMACS/trajectory analysis), structural comparison and
superposition, pocket comparison, AI-assisted prioritisation, a documented
plugin API and multi-user deployment.
